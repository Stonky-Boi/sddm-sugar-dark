# Weyland-Yutani Login Theme for SDDM

A completely stripped-down, terminal-based sci-fi login interface for SDDM, inspired by Alien / Nostromo aesthetics. 

### The Blueprint
This project is a heavy fork of the excellent [Sugar Dark](https://github.com/MarianArlt/sddm-sugar-dark) theme by Marian Arlt. The original graphical interface, virtual keyboard, and visual bloat have been stripped away to leave a pristine, code-driven terminal login experience.
